## La idea: elegir el método antes de escribir

Una **demostración** es una cadena de pasos lógicos que prueba que una afirmación es cierta (o falsa) **siempre**, no solo en los ejemplos que has probado. La diapositiva 14 da cuatro métodos. Lo primero, antes de escribir nada, es elegir cuál:

## Los cuatro métodos en una tabla

| Método | Cuándo | Cómo empieza | Ejemplo de la D14 |
| --- | --- | --- | --- |
| **Directa** | Propiedades de pares, impares, divisibilidad, cuadrados | «Sea n = 2k…» y operar hasta la forma pedida | Par + impar es impar |
| **Contradicción** | «No existe…», «no puede…», «es irracional» | «Supongamos que sí existe…» y llegar a algo imposible | √2 es irracional |
| **Inducción** | «Para todo n ∈ ℤ⁺» con sumas, divisibilidad o desigualdades | Caso base, hipótesis, paso, conclusión | 1 + 2 + ⋯ + n + ⋯ + 2 + 1 = n² |
| **Contraejemplo** | La afirmación es falsa | Un caso concreto que la incumple | Si 4 divide a n², ¿divide a n? (n = 2) |

## Traducir al álgebra

| Frase | Se escribe | Ojo |
| --- | --- | --- |
| n es par | n = 2k, con k ∈ ℤ | |
| n es impar | n = 2k + 1, con k ∈ ℤ | |
| Dos números cualesquiera | **letras distintas**: 2k y 2m | Con la misma k serían el mismo número o consecutivos |
| x divide a y | y = x·a, con a ∈ ℤ | |
| n es cuadrado perfecto | n = a², con a ∈ ℤ | |
| a/b es irreducible | a y b no tienen factores comunes | Es la clave de √2 |

## Errores típicos

| Error | Cómo se ve | Cómo evitarlo |
| --- | --- | --- |
| Demostrar con ejemplos | «2 + 3 = 5, 4 + 7 = 11, luego par + impar es impar» | Los ejemplos convencen; la demostración usa 2k y 2m + 1 |
| La misma letra para dos números | Par 2k e impar 2k + 1 | Así solo demuestras el caso de dos consecutivos |
| Negar mal en contradicción | Para «no existen enteros con…» suponer «no existen» | Hay que suponer lo contrario: «sí existen n y m con…» |
| No decir dónde está la contradicción | Acabar en 2(c² − b) = 1 sin comentarlo | Explica: «un par no puede valer 1» |
| Contraejemplo sin comprobar | Decir «n = 2» y nada más | Comprueba que cumple la hipótesis y no la conclusión |

## Vocabulario en inglés

*Direct proof* (demostración directa), *proof by contradiction* (por contradicción o reducción al absurdo), *counterexample* (contraejemplo), *even / odd* (par / impar), *divides* (divide a), *perfect square* (cuadrado perfecto), *irrational* (irracional), *integer* (entero).
