Sumas de series

El caso n + 1 es el caso n más un término. Hipótesis, término nuevo y factor común.

Mapa del temaEjercicios1 · Sumas2 · Divisibilidad3 · Desigualdades

Idea clave: el caso n + 1 es el caso n más un término

En una suma, la hipótesis te da el valor de todo lo anterior; tú solo tienes que añadir el término nuevo y arreglar la expresión hasta que tenga la forma del objetivo.

1+2+⋯+n+(n+1)=[1+2+⋯+n]+(n+1)\displaystyle 1 + 2 + \cdots + n + (n + 1) = [1 + 2 + \cdots + n] + (n + 1)1+2+⋯+n+(n+1)=[1+2+⋯+n]+(n+1)

El corchete es exactamente la hipótesis. Y el truco para arreglar lo que queda es sacar factor común, no desarrollar.

¿Por qué factorizar y no desarrollar? Porque el objetivo casi siempre viene factorizado, como (n+1)(n+2)2\displaystyle \frac{(n + 1)(n + 2)}{2}2(n+1)(n+2)​. Si sacas factor común, te acercas a esa forma. Si desarrollas, obtienes un polinomio y luego tienes que factorizarlo, que es más largo y más fácil de fallar.

Método

  1. Escribe el término general con su índice r y sustituye r = n + 1: ese es el término nuevo.
  2. Escribe el objetivo: la fórmula con n + 1 en lugar de n, con paréntesis.
  3. Separa el término nuevo y sustituye el resto por la hipótesis.
  4. Saca factor común de lo que aparezca en el objetivo y simplifica lo que queda dentro.

Ejemplo 1 · 1+2+⋯+n=n(n+1)2\displaystyle 1 + 2 + \cdots + n = \frac{n(n + 1)}{2}1+2+⋯+n=2n(n+1)​

Explorar. n = 1: 1 y 1⋅22=1\displaystyle \frac{1\cdot 2}{2} = 121⋅2​=1. n = 2: 3 y 2⋅32=3\displaystyle \frac{2\cdot 3}{2} = 322⋅3​=3. n = 3: 6 y 3⋅42=6\displaystyle \frac{3\cdot 4}{2} = 623⋅4​=6. Parece cierto.

  1. Enunciado. Sea P(k): 1+2+⋯+k=k(k+1)2\displaystyle 1 + 2 + \cdots + k = \frac{k(k + 1)}{2}1+2+⋯+k=2k(k+1)​, para k ∈ ℤ⁺.
  2. Caso base, k = 1. Lado izquierdo: 1. Lado derecho: 1⋅22=1\displaystyle \frac{1\cdot 2}{2} = 121⋅2​=1. Coinciden, así que P(1) es cierta.
  3. Hipótesis de inducción. Supongamos que P(k) es cierta para k = n: 1+2+⋯+n=n(n+1)2\displaystyle 1 + 2 + \cdots + n = \frac{n(n + 1)}{2}1+2+⋯+n=2n(n+1)​.
  4. Paso inductivo, k = n + 1. Queremos llegar a: 1+2+⋯+n+(n+1)=(n+1)(n+2)2\displaystyle 1 + 2 + \cdots + n + (n + 1) = \frac{(n + 1)(n + 2)}{2}1+2+⋯+n+(n+1)=2(n+1)(n+2)​.

1+2+⋯+n+(n+1)=n(n+1)2+(n+1)\displaystyle 1 + 2 + \cdots + n + (n + 1) = \frac{n(n + 1)}{2} + (n + 1)1+2+⋯+n+(n+1)=2n(n+1)​+(n+1) (por la hipótesis)

=(n+1)⋅(n2+1)\displaystyle = (n + 1) \cdot \left(\frac{n}{2} + 1\right)=(n+1)⋅(2n​+1) (factor común n + 1)

=(n+1)(n+2)2\displaystyle = \frac{(n + 1)(n + 2)}{2}=2(n+1)(n+2)​ ✔ es el objetivo

¿Por qué (n + 1) como factor común? Porque está en los dos sumandos y también en el objetivo. Mira el objetivo, busca qué factores tiene, y sácalos.

  1. Conclusión. Como P(k) es cierta para k = 1, y si es cierta para k = n también lo es para k = n + 1, por el principio de inducción es cierta para todo k ∈ ℤ⁺.

Ejemplo 2 · 1⋅2+2⋅3+⋯+n(n+1)=n(n+1)(n+2)3\displaystyle 1\cdot 2 + 2\cdot 3 + \cdots + n(n + 1) = \frac{n(n + 1)(n + 2)}{3}1⋅2+2⋅3+⋯+n(n+1)=3n(n+1)(n+2)​

Explorar.

n Suma Resultado n(n+1)(n+2)3\displaystyle \frac{n(n + 1)(n + 2)}{3}3n(n+1)(n+2)​
1 1·2 2 1⋅2⋅33=2\displaystyle \frac{1\cdot 2\cdot 3}{3} = 231⋅2⋅3​=2
2 2 + 2·3 8 2⋅3⋅43=8\displaystyle \frac{2\cdot 3\cdot 4}{3} = 832⋅3⋅4​=8

Fíjate en la columna «Suma»: cada fila es la anterior más un término. Eso es el paso inductivo en pequeño.

  1. Enunciado. Sea P(k): 1⋅2+2⋅3+⋯+k(k+1)=k(k+1)(k+2)3\displaystyle 1\cdot 2 + 2\cdot 3 + \cdots + k(k + 1) = \frac{k(k + 1)(k + 2)}{3}1⋅2+2⋅3+⋯+k(k+1)=3k(k+1)(k+2)​, para k ∈ ℤ⁺.
  2. Caso base, k = 1. Lado izquierdo: 1·2 = 2. Lado derecho: 1⋅2⋅33=2\displaystyle \frac{1\cdot 2\cdot 3}{3} = 231⋅2⋅3​=2. Coinciden.
  3. Hipótesis de inducción. Para k = n: 1⋅2+2⋅3+⋯+n(n+1)=n(n+1)(n+2)3\displaystyle 1\cdot 2 + 2\cdot 3 + \cdots + n(n + 1) = \frac{n(n + 1)(n + 2)}{3}1⋅2+2⋅3+⋯+n(n+1)=3n(n+1)(n+2)​.
  4. Paso inductivo, k = n + 1. Queremos llegar a: 1⋅2+⋯+n(n+1)+(n+1)(n+2)=(n+1)(n+2)(n+3)3\displaystyle 1\cdot 2 + \cdots + n(n + 1) + (n + 1)(n + 2) = \frac{(n + 1)(n + 2)(n + 3)}{3}1⋅2+⋯+n(n+1)+(n+1)(n+2)=3(n+1)(n+2)(n+3)​.

¿Cuál es el término nuevo? El término general es r(r + 1). El término número n + 1 se obtiene poniendo r = n + 1: (n+1)(n+2)(n + 1)(n + 2)(n+1)(n+2). No es n(n + 1) + 1: hay que sustituir, no sumar 1 al final.

1⋅2+⋯+n(n+1)+(n+1)(n+2)=n(n+1)(n+2)3+(n+1)(n+2)\displaystyle 1\cdot 2 + \cdots + n(n + 1) + (n + 1)(n + 2) = \frac{n(n + 1)(n + 2)}{3} + (n + 1)(n + 2)1⋅2+⋯+n(n+1)+(n+1)(n+2)=3n(n+1)(n+2)​+(n+1)(n+2) (por la hipótesis)

=(n+1)(n+2)⋅(n3+1)\displaystyle = (n + 1)(n + 2) \cdot \left(\frac{n}{3} + 1\right)=(n+1)(n+2)⋅(3n​+1) (factor común (n + 1)(n + 2))

=(n+1)(n+2)(n+3)3\displaystyle = \frac{(n + 1)(n + 2)(n + 3)}{3}=3(n+1)(n+2)(n+3)​ ✔ es el objetivo

¿Y si hubiera desarrollado? Te habría salido n3+6n2+11n+63\displaystyle \frac{n^{3} + 6n^{2} + 11n + 6}{3}3n3+6n2+11n+6​ y tendrías que darte cuenta de que eso es (n+1)(n+2)(n+3)3\displaystyle \frac{(n + 1)(n + 2)(n + 3)}{3}3(n+1)(n+2)(n+3)​. Se puede, pero es más largo y cada multiplicación es una ocasión de equivocarse.

  1. Conclusión. Como P(k) es cierta para k = 1, y si es cierta para k = n también lo es para k = n + 1, por el principio de inducción es cierta para todo k ∈ ℤ⁺.

Relacionar patrones: la escalera de fórmulas

Pon las dos fórmulas una encima de otra y aparece una regularidad:

La tercera fórmula no la hemos demostrado, pero el patrón te deja adivinarla. Y su paso inductivo sería el mismo: sacar factor común (n + 1)(n + 2)(n + 3) y queda (n4+1)=n+44\displaystyle \left(\frac{n}{4} + 1\right) = \frac{n + 4}{4}(4n​+1)=4n+4​. Ejercicio: demuéstrala tú.

Esto también sirve para descubrir fórmulas. Como n(n + 1) = n² + n, la suma de los n(n + 1) es la suma de los cuadrados más la suma de los números. Despejando:

Que es justo la fórmula que tu profesor te pide demostrar en el ejercicio D16·9. Ahora ya sabes de dónde sale.

Variantes que vas a encontrar en los ejercicios

La estrategia es siempre la misma: término nuevo + hipótesis, y factor común de lo que tenga el objetivo. Lo que cambia es cómo encontrar el factor común:

  • Con factoriales. Usa que (n+2)!=(n+2)⋅(n+1)!(n + 2)! = (n + 2) \cdot (n + 1)!(n+2)!=(n+2)⋅(n+1)!. Así (n + 1)! queda como factor común.
  • Con potencias en el denominador, como 12n−1\displaystyle \frac{1}{2^{n-1}}2n−11​ y 12n\displaystyle \frac{1}{2^{n}}2n1​. Pasa todo al denominador mayor: 12n−1=22n\displaystyle \frac{1}{2^{n-1}} = \frac{2}{2^{n}}2n−11​=2n2​. Luego suma los numeradores.
  • Con productos como n(n + 2). Igual que el ejemplo 2. El término nuevo es (n + 1)(n + 3), y el factor común es (n + 1).
