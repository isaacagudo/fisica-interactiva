D33·4 · Suma con factoriales

Mapa del temaEjercicios1 · Sumas2 · Divisibilidad3 · Desigualdades

Enunciado · Diapositiva 33, ejercicio 4

Demuestra, utilizando la inducción matemática, que 1·1! + 2·2! + ⋯ + n·n! = (n + 1)! − 1, con n ∈ ℤ⁺.

Patrón: Sumas de seriesCaso base: k = 1

Antes de demostrar, comprueba que te crees el enunciado y mira desde qué número se cumple.

La tabla se calcula al abrir la página en el navegador.

Resuélvelo con pistas

Escribe la demostración en la libreta con las cinco partes de la plantilla: enunciado, caso base, hipótesis (k = n), paso (k = n + 1) y conclusión. Si te atascas, abre la siguiente pista: cada una te deja un poco más cerca, pero no lo resuelve todo.

Pista 1El término nuevo y el objetivo

El término nuevo es (n + 1)·(n + 1)! y el objetivo es (n + 2)! − 1.

Pista 2La hipótesis

Queda (n + 1)! − 1 + (n + 1)·(n + 1)!. Deja el −1 aparte: no lo toques, porque también está en el objetivo.

Pista 3El truco

Saca (n + 1)! factor común: (n + 1)! · (1 + n + 1) − 1.

Pista 4La última cuenta

Usa que (n + 2) · (n + 1)! = (n + 2)!.

Solución completaLas cinco partes
  1. Sea P(k): 1·1! + ⋯ + k·k! = (k + 1)! − 1, para k ∈ ℤ⁺.
  2. Caso base, k = 1. Lado izquierdo: 1·1! = 1. Lado derecho: 2! − 1 = 1. Coinciden.
  3. Hipótesis, k = n. 1·1! + ⋯ + n·n! = (n + 1)! − 1.
  4. Paso, k = n + 1. Queremos llegar a (n + 2)! − 1.

1·1! + ⋯ + n·n! + (n + 1)·(n + 1)! = (n + 1)! − 1 + (n + 1)·(n + 1)! (por la hipótesis)

= (n + 1)! · (n + 2) − 1 (factor común (n + 1)!)

= (n + 2)! − 1 ✔

  1. Conclusión. Como P(k) es cierta para k = 1, y si es cierta para k = n también lo es para k = n + 1, por el principio de inducción es cierta para todo k ∈ ℤ⁺.
