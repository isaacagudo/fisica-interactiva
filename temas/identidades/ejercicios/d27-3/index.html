D27·3 · 2cos²x = sen 2x

MapaEjercicios1 · Identidades2 · Ángulo doble3 · Ecuaciones4 · Sinusoide

Enunciado · Diapositiva 27, ejercicio

Resuelve la ecuación 2cos²x = sen 2x para 0 ≤ x < 2π, dando los resultados en términos de π.

Apartado: Ecuaciones en un intervaloNivel 3 · tipo examen

Resuélvelo con pistas

Hazlo primero en la libreta. Si te atascas, abre la siguiente pista: cada una te deja un poco más cerca, pero no lo resuelve todo.

Pista 1Haz el dibujo

Dibuja 2cos²x y sen 2x en [0, 2π) y busca dónde se cortan.

Ver mi dibujo
Pista 2Ángulo doble y factor común

sen 2x = 2 sen x cos x. Queda 2cos x(cos x − sen x) = 0.

ResultadoSolo para comprobar

x=π4,π2,5π4 y 3π2\displaystyle x = \frac{\pi}{4}, \frac{\pi}{2}, \frac{5\pi}{4}\ \text{y}\ \frac{3\pi}{2}x=4π​,2π​,45π​ y 23π​

Solución completaPaso a paso

2cos⁡2x−2sen⁡xcos⁡x=0⇒2cos⁡x(cos⁡x−sen⁡x)=0\displaystyle 2\operatorname{cos}^{2} x - 2 \operatorname{sen} x \operatorname{cos} x = 0 \Rightarrow 2\operatorname{cos} x(\operatorname{cos} x - \operatorname{sen} x) = 02cos2x−2senxcosx=0⇒2cosx(cosx−senx)=0

cos⁡x=0⇒x=π2,3π2\displaystyle \operatorname{cos} x = 0 \Rightarrow x = \frac{\pi}{2}, \frac{3\pi}{2}cosx=0⇒x=2π​,23π​

cos⁡x=sen⁡x⇒tan⁡x=1⇒x=π4,5π4\displaystyle \operatorname{cos} x = \operatorname{sen} x \Rightarrow \operatorname{tan} x = 1 \Rightarrow x = \frac{\pi}{4}, \frac{5\pi}{4}cosx=senx⇒tanx=1⇒x=4π​,45π​

¿Se puede dividir entre cos x para pasar a tan x? Solo en el segundo factor, después de haber sacado aparte el caso cos x = 0.
